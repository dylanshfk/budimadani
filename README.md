# budimadani

This app allows users to calculate fuel prices. Users simply need to key in the number of liters, and the app will calculate the fuel price based on fuel type.

It should be noted that at the moment, this app is only relying on offline pricing for now (which means the developer will need to update prices manually every week).

Fuel price changes occur on Thursdays, with prices announced on Wednesdays (a few hours before the price change takes effect).
